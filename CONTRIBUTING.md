# AuthorityGate RackSight Contribution Policy

Copyright (c) 2026 AuthorityGate

RackSight is published as open-source software under the MIT License, but AuthorityGate does not operate it as a community-maintained project.

## Pull requests

External pull requests are not accepted. Pull requests opened against this repository are closed automatically without review. Do not create feature branches in the AuthorityGate repository.

The repository uses exactly two maintained branches:

- `main` — stable releases and the default branch
- `Dev` — active AuthorityGate development

## Support

AuthorityGate provides no support, service-level commitment, implementation assistance, compatibility guarantee, or obligation to fix defects. Users are responsible for evaluating, securing, operating, and modifying the software for their own environments.

Public documentation may be used to diagnose problems. Opening a discussion, issue, email, or other communication does not create a support obligation.
